# Roadmap

Planned features and enhancements for the Financial Accounting System.

---

## Next Priorities (v0.0.5+)

### Banking Module

- **Bank Statement Import** — Parse MT940/CAMT.053 formats
- **Payment Order Generation** — Export to bank formats (MT101, SEPA XML)
- **Statement Reconciliation** — Match imported transactions with documents
- **Bulk Operations** — Create/post multiple documents at once

### Core Module

- **Multi-currency Conversion** — Transfer between accounts in different currencies
- **FX Gain/Loss Tracking** — Automatic calculation of exchange differences
- **Multi-currency Reporting** — Reports in base and foreign currencies

### Security & Compliance

- **Authentication** — OAuth2/OIDC integration
- **Authorization** — Role-based access control (RBAC)
- **Audit Trail** — Enhanced user action logging

### Reporting & Analysis

- **Budget vs Actual** — Variance analysis reports
- **Cash Flow Forecast** — Predictive analytics
- **Custom Reports** — User-defined report builder
- **Export Formats** — PDF, Excel, CSV reports
